Kebijakan Privasi

Berlaku sejak 5 Agustus 2026

Aplikasi ini tidak memiliki server, sistem akun, atau SDK analitik/iklan apa pun. Semua yang Anda masukkan hanya disimpan di penyimpanan lokal perangkat Anda sendiri. Tidak ada yang dikirim ke mana pun.

Ringkasan

DiabestMeal ("Aplikasi") adalah aplikasi catatan makan pribadi, resep, dan pemantauan kesehatan untuk menghitung kalori dan perencanaan makan yang ramah diabetes. Kebijakan ini menjelaskan apa yang terjadi pada data Anda saat menggunakan Aplikasi.

Data yang kami kumpulkan

Tidak ada, dari pihak kami. Kami (pengembang) tidak pernah menerima, melihat, atau memiliki akses ke data apa pun yang Anda masukkan ke Aplikasi. Tidak ada server backend untuk Aplikasi ini mengirim data ke mana pun.

Data yang Anda simpan di perangkat Anda

  • Informasi profil (usia, jenis kelamin, tinggi, berat, tingkat aktivitas, target berat badan)
  • Catatan makan (makanan yang dicatat, jumlah, tanggal)
  • Hasil lab yang Anda masukkan sendiri (gula darah, HbA1c, kolesterol, asam urat, kreatinin, dll.)
  • Riwayat catatan berat badan
  • Makanan custom yang Anda tambahkan
  • Favorit dan preferensi bahasa

Data ini tetap ada di perangkat Anda menggunakan penyimpanan aplikasi lokal standar. Data ini tidak pernah diunggah, disinkronkan ke cloud, atau dibagikan ke pengembang maupun pihak ketiga mana pun.

Layanan pihak ketiga

Aplikasi ini tidak menggunakan layanan pihak ketiga apa pun. Tidak ada analitik, layanan pelaporan crash, jaringan iklan, atau API database makanan pihak ketiga. Semua data nutrisi sudah tertanam di dalam Aplikasi itu sendiri. Situs web diabestmeal.com ini sendiri (terpisah dari Aplikasi) menggunakan Cloudflare Web Analytics yang tanpa cookie untuk menghitung trafik halaman.

File backup

Aplikasi memungkinkan Anda mengekspor file backup (JSON biasa) secara manual lewat share sheet bawaan perangkat, supaya Anda bisa menyimpannya ke cloud storage, email, atau aplikasi file milik Anda sendiri sebelum ganti HP. File ini tidak dienkripsi, simpan di tempat yang cukup privat, karena bisa berisi informasi terkait kesehatan yang Anda masukkan (seperti hasil lab). Pengembang tidak pernah menerima salinan file ini; ekspor dan impor sepenuhnya terjadi di perangkat Anda.

Penyimpanan dan penghapusan data

Data Anda tetap ada di perangkat selama Aplikasi terinstal. Anda bisa menghapus semua data Aplikasi kapan saja lewat Pengaturan → Reset All Data, atau dengan uninstall Aplikasi. Karena tidak ada yang tersimpan di server, tidak ada lagi yang perlu kami hapus di pihak kami.

Privasi anak

Aplikasi ini tidak dengan sengaja mengumpulkan data dari siapa pun, termasuk anak-anak, karena Aplikasi memang tidak mengumpulkan data sama sekali, semua dimasukkan secara sukarela oleh pengguna dan disimpan secara lokal. Aplikasi ini tidak ditujukan untuk anak-anak dan dimaksudkan untuk penggunaan umum orang dewasa dalam pemantauan diet/kesehatan pribadi.

Disclaimer medis

Aplikasi ini menyediakan informasi nutrisi dan pemantauan kesehatan umum untuk mendukung perencanaan makan sehari-hari. Ini bukan alat medis dan tidak memberikan saran, diagnosis, atau perawatan medis. Rentang referensi hasil lab yang ditampilkan adalah rentang referensi klinis umum, bukan diagnosis pribadi. Selalu konsultasikan kondisi kesehatan Anda ke dokter atau ahli gizi yang berkualifikasi.

Perubahan kebijakan ini

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di URL yang sama dengan tanggal "Berlaku sejak" yang baru.
